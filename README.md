# Portfolio simple con Astro

Solo hay 3 archivos que importan:

- `src/pages/index.astro`  -> toda la página (tus datos arriba, el HTML debajo, scripts al final)
- `src/styles/global.css`  -> colores y estilos
- `public/img/`            -> tus imágenes

## Arrancar
    npm install
    npm run dev      (abre http://localhost:4321)
